# Документация PoSoc

Человекочитаемая документация протокола. Нормативный источник истины — спецификация в [specs/](../specs/index.md) (у неё свой [индекс](../specs/index.md)).

| Path | Summary |
|---|---|
| [posoc-concept.md](posoc-concept.md) | Концепция протокола: что это, как устроено (идентичность, записи, связи, L0, иерархия, доверие), почему так, гарантии и негарантии, ключевые параметры, ограничения v0.12. Только принципы, алгоритмы и математика — без деталей реализации. |
| [posoc-implementation.md](posoc-implementation.md) | Детали реализации: криптография (Ed25519/BLAKE3/CBOR) и объёмы записей, форматы записей и канонизация (включая `KEY_LOSS`), транспорт = соцграф, sync queue, gossip/anti-entropy, обязательные компоненты эталонной реализации. |
| [posoc-plain.md](posoc-plain.md) | Объяснение PoSoc для читателей без технической подготовки: зачем нужна сеть взаимного подтверждения, как устроены идентичность, связи и их разрывы, малые группы и сообщества, как каждый отвечает на вопрос «человек ли это» и чего система не обещает. |
