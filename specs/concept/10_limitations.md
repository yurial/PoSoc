## 10. Ограничения и открытые вопросы

<a id="lim-10"></a>

<a id="lim-10.1"></a>

1. **Namespace:** имперсонация имён нерешаема; identity — структура.

<a id="lim-10.2"></a>

2. **Многоличность:** принципиально не детектируется; смягчения — стоимость связей, эвристики.

<a id="lim-10.3"></a>

3. **Публичность согласия:** видны составы и declarations; приватизация — [ZKP-11](11_privacy_zkp.md#zkp-11).

<a id="lim-10.4"></a>

4. **Мажоритарная жёсткость:** индивидуум не привяжется без большинства своей L0.

<a id="lim-10.5"></a>

5. **Сговор выше порогов:** выше $\kappa$ — вне гарантий.

<a id="lim-10.6"></a>

6. **Спам:** структурно ограничен; остаточное — объёмы буферов.

<a id="lim-10.7"></a>

7. **Грифинг ядом:** каскады сжимают окна; взаимные marks (≤2 на пару) усиливают взаимный грифинг пары; ограничители — конечность, truce; остаточный риск признан.

<a id="lim-10.8"></a>

8. **Hijack и клиентские политики:** явные подтверждения операций; предупреждения о контрагентах с историей revoke.

<a id="lim-10.9"></a>

9. **Цензура соседа:** утаивание записей; anti-entropy и multi-parenting смягчают; единственный мост — риск.

<a id="lim-10.10"></a>

10. **Доступность данных:** prover может скрывать записи; spot-check ([TRUST-6.3](06_trust.md#trust-6.3)) смягчает; скоординированное сокрытие — остаточный риск.

<a id="lim-10.11"></a>

11. **Дрейф порогов при росте:** рост брата повышает парный порог при статичных связях — мгновенный detach и дорогой возврат ($T_{hold}$); живучесть — multi-parenting.

<a id="lim-10.12"></a>

12. **Сложность вывода:** all-pairs — $O(\sum_H k_H^2)$ за пересчёт; обязательны индексы и инкрементальность.

<a id="lim-10.13"></a>

13. **Консервативность rounds:** синхронное удаление — не максимальный roster; осознанно (soundness важнее полноты).

<a id="lim-10.14"></a>

14. **Расхождения часов:** влияют на мгновенные виды, не на сходимость; $\Delta$ покрывает скью.

<a id="lim-10.15"></a>

15. **Управление параметрами:** изменение = форк; governance не специфицирован.

<a id="lim-10.16"></a>

16. **Squeeze-out (growth priority):** присоединение может вытеснить incumbents на пороге вплоть до quench; враждебный join стоит vouch-quorum и разрушает также членство атакующего; осознанная цена детерминизма и отсутствия задержек.

<a id="lim-10.17"></a>

17. **Транспортная инженерия:** relay-политика, пропускная способность, объёмы хранилищ — вне спецификации.
