## 5. Эмерджентная иерархия

<a id="hier-5"></a>

### 5.1 Принцип

<a id="hier-5.1"></a>

Явные акты — связи, membership в L0, declarations. Edges, levels, валидность — выводимое состояние, перевычисляемое непрерывно.

### 5.2 Declarations

<a id="hier-5.2"></a>

1. <a id="hier-5.2.1"></a>**`DECLARE(P,H)`** — подписанное $P$ утверждение «поддерживаю принадлежность сообществ, где я состою, к $H$»: голос в C1-quorum **каждого** $X$ с $P \in R_{str}(X)$. TTL $T_{life}$, тихо автопродлевается (rate-limit [ARCH-2.6.3](02_architecture.md#arch-2.6.3)). Одна declaration голосует во всех соответствующих quorum — один человек, одно согласие; disjoint count по уникальным pk исключает двойной счёт.
2. <a id="hier-5.2.2"></a>**`DECLARE_REVOKE(P,H)`** — мгновенный односторонний отзыв (лёгкое возражение): живость declaration обрезается в $t_{sign}$; quorum падает → edge отрывается мгновенно. Осцилляция REVOKE↔DECLARE самонаказуема (отрыв мгновенный, возврат — через $T_{hold}$).
3. <a id="hier-5.2.3"></a>**Адрес группы** $ID_H$ ([FMT-2.8](../implementation/01_records_formats.md#fmt-2.8)); имя — не identity ([LIM-10.1](10_limitations.md#lim-10.1)); identity сообщества — структура.
4. <a id="hier-5.2.4"></a>**Isolate** — группа без живых детей: $R_{str} = \varnothing$, адрес не хранится сетью (владелец хранит), бутстрапится ([HIER-5.5](#hier-5.5)). Declarations посторонних не хранятся ([ARCH-2.6.1](02_architecture.md#arch-2.6.1), [ARCH-2.4.9](02_architecture.md#arch-2.4.9)).

### 5.3 Rosters

<a id="hier-5.3"></a>

1. <a id="hier-5.3.1"></a>$R_{decl}(H)$ — участники с живыми declarations: заявления, **не носители доверия, в порогах не участвуют**.
2. <a id="hier-5.3.2"></a>$R_{str}(H) = \bigcup_{C \in \mathrm{children}(H)} R_{str}(C)$ по уникальным pk; для L0 — активный roster [L0-4](04_l0.md#l0-4); isolate — $\varnothing$.
3. <a id="hier-5.3.3"></a>Участник «в иерархии» ⟺ состоит в валидной L0, транзитивно привязанной к доверенному компоненту.
4. <a id="hier-5.3.4"></a>Разделение ростеров исключает циркулярность.

### 5.4 Thresholds и disjoint count

<a id="hier-5.4"></a>

1. <a id="hier-5.4.1"></a>**Disjoint count:**
$$U_{X \Rightarrow Y} = \big|\{\,p \in R_{str}(X):\ \exists\, q \in R_{str}(Y) \setminus R_{str}(X),\ \text{связь } (p,q) \text{ активна}\,\}\big|$$
2. <a id="hier-5.4.2"></a>**Пороги** ($avg = (|X|+|Y|)/2$, $\rho = |big|/|small|$, $f = f(avg)$, $\kappa = \kappa(avg)$):
$$f(m) = \begin{cases} 0.5, & m < 30 \\ 0.05 + 0.45 \cdot 1.5^{-\log_{10}(m/30)}, & 30 \le m \le 10^4 \\ 0.05 + 0.1618 \cdot 4^{-\log_{10}(m/10^4)}, & m > 10^4 \end{cases}$$
$$\gamma(\rho) = \min(1,\ f + c(\rho-1)),\ c = 0.25;\qquad \kappa(m) = \min(\lfloor m/2.5 \rfloor,\ 4500)$$
$$t_{big} = \min\big(|big|,\ \max(\lfloor f \cdot |big| \rfloor,\ \kappa) + 1\big),\qquad t_{small} = \min\big(|small|,\ \max(\lfloor f \cdot |small| \rfloor,\ \lfloor \gamma \cdot |small| \rfloor,\ \kappa) + 1\big)$$
3. <a id="hier-5.4.3"></a>**Пара проходит** ⟺ $U_{X \Rightarrow Y} \ge t_X$ ∧ $U_{Y \Rightarrow X} \ge t_Y$.
4. <a id="hier-5.4.4"></a>**Инварианты:** (i) при непустых внешних частях и полной взаимной внешней связности пара проходит (при большом пересечении ростеров внешние части малы — оговорка существенна); (ii) $t \le |side|$; (iii) равные пары: $t = \min(m, \max(\lfloor f\,m \rfloor, \kappa(m)) + 1)$; (iv) $\rho{=}1$, $m<30$: $t = \lfloor m/2 \rfloor + 1$; (v) асимметрия — цена до единогласия малой стороны.
5. <a id="hier-5.4.5"></a>**Лемма (инъекция одного ключа).** Угнанный аккаунт + 30 сибил-ключей: $U_{X \Rightarrow Y} = 30 \ge t_X$, но $U_{Y \Rightarrow X} = 1 < t_Y$ — двусторонность отбивает инъекцию через один человеческий ключ.

### 5.5 Live edge: условия, активация, bootstrap, freeze

<a id="hier-5.5"></a>

<a id="hier-5.5.1"></a>

**Статусы групп:** *isolate* (0 живых детей, $R_{str} = \varnothing$, без уровня); *vertex* (≥ 2 живых детей); *free group* (1 живой ребёнок — возникает только понижением vertex; edge грандфатерится; приём детей и привязка вверх — на общих основаниях).

<a id="hier-5.5.2"></a>

**Edge $X \to H$ жив на $\tau$ ⟺ непрерывно:**

- <a id="hier-5.5.3"></a>**C1 (consent):** ≥ $\lfloor |X|/2 \rfloor + 1$ участников $R_{str}(X)$ имеют живые declarations в $H$;
- <a id="hier-5.5.4"></a>**C2 (corroboration, all-pairs):** для **каждого** живого ребёнка $Y \in \mathrm{children}(H) \setminus \{X\}$ пара $(X,Y)$ проходит;
- <a id="hier-5.5.5"></a>**C3 (acyclicity):** не существует пути $H \Rightarrow^* X$ по живым рёбрам.

**Активация.**

- <a id="hier-5.5.6"></a>**Attach к живой группе** (≥ 1 живого ребёнка у $H$; $R_{str}(X) \ne \varnothing$ — иначе C1 невыполним): C1–C3 выполняются непрерывно $T_{hold}$ → активация. Проверка пар кандидата со всеми живыми детьми делает активацию безопасной для них.
- <a id="hier-5.5.7"></a>**Freeze ∥ hold window.** Freeze не приостанавливает накопление окна; активация в $\max(\text{конец freeze},\ \text{конец окна})$.
- <a id="hier-5.5.8"></a>**Freeze:** $T_f$ от `L0_GENESIS` и от bootstrap-активации вершины; блокирует только **новые** активации рёбер вверх; существующие рёбра и дети не затрагиваются.

**Bootstrap пустой группы $H$:**

1. <a id="hier-5.5.9"></a>**Candidates** $K$: группы с живым C1-quorum к $H$.
2. <a id="hier-5.5.10"></a>**S-set:** $S \subseteq K$, $|S| \ge 2$, все пары **внутри $S$** проходят. Существование одного $S$ достаточно — кандидаты вне $S$ ничего не блокируют (anti-DoS: сибил без внешних связей не входит ни в одно $S$).
3. <a id="hier-5.5.11"></a>**Окно:** для фиксированного $S$ — непрерывное выполнение условий всех его членов $\ge T_{hold}$; изменение состава $S$ (потеря члена, падение пары) перезапускает окно **этого** $S$; события кандидатов вне $S$ окно не перезапускает.
4. <a id="hier-5.5.12"></a>**Выбор при активации:** среди $S$ с завершённым окном — inclusion-maximal; при одновременном завершении несравнимых — окно с более ранним стартом; при равенстве — лексикографически наименьший отсортированный список $ID$.
5. <a id="hier-5.5.13"></a>**Эффект:** $\mathrm{children}(H) = S$; $R_{str}(H) = \bigcup$; freeze $T_f$ для $H$; прочие кандидаты присоединяются после по общим правилам attach.

<a id="hier-5.5.14"></a>

Одновременные активации оцениваются в детерминированном порядке — по $(t_{sign},\ H)$ объекта-условия; активированное ребро цикла создать не может (C3).

### 5.6 Динамика: мгновенный пересчёт

<a id="hier-5.6"></a>

1. <a id="hier-5.6.1"></a>**Detach — мгновенный.** Провал C1 у edge **или** провал любой пары $(Y_i, Y_j)$ → **оба** edge пары отпадают немедленно; $H$ пересчитывается немедленно.
2. <a id="hier-5.6.2"></a>**Понижение.** Живых детей $< 2$: при 1 — vertex → **free group** (edge грандфатерится, $L = 1 + L(\text{ребёнка})$); при 0 — **isolate**, восходящие edges отваливаются **тем же пересчётом** (C1 при пустом $R_{str}$ невыполним). Изолят привязывается **только bootstrap-ом**. Рёбра детей сохраняются; каскад — полный мгновенный пересчёт без искусственных задержек.
3. <a id="hier-5.6.3"></a>**Levels:** $L(H) = 1 + \max_C L(C)$; isolate — без уровня; метаданные. Ожидаемая глубина при ширине $\bar k \sim 5\text{–}10$: $D \approx \log_{\bar k}(P/\overline{|L0|}) \approx 7\text{–}10$.
4. <a id="hier-5.6.4"></a>**Параллелизм:** multi-parenting — штатное состояние DAG; дети не блокируются ничем, кроме собственного freeze.
5. <a id="hier-5.6.5"></a>**Пересчёт:** непрерывный; пороги всегда по текущим структурным численностям (дрейф — [LIM-10.11](10_limitations.md#lim-10.11)).

### 5.7 Возражения и выход

<a id="hier-5.7"></a>

1. <a id="hier-5.7.1"></a>**Лёгкое** — `DECLARE_REVOKE`: quorum C1 падает, edge отрывается мгновенно.
2. <a id="hier-5.7.2"></a>**Тяжёлое** — `LINK_REVOKE` ([LINK-3.2](03_links.md#link-3.2)).
3. <a id="hier-5.7.3"></a>**Выход группы из родителя** — массовый `DECLARE_REVOKE` членов $X$; отдельного события нет.

### 5.8 Изоляция ботов

<a id="hier-5.8"></a>

Declarations permissionless, но: quorum L0 контролируются людьми; isolate имеет пустой $R_{str}$; disjoint count исключает co-membership; каждая пара на пути бот-поддерева в человеческую иерархию требует живых человеческих связей с TTL ≤ $T_{life}$. Одиночные edges (free groups) обхода не открывают: соединяющее ребро встречает сестёр (self-healing — оторванное от людей поддерево теряет корроборацию не позже $T_{life}$).

### 5.9 Мотивация связей

<a id="hier-5.9"></a>

Алгоритм не регламентирует, кого подтверждать; предполагается, что реальных связей достаточно для связывания графа.
