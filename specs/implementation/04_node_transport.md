# Транспорт и узловая инженерия

> Транспортный раздел (implementation): полная транспортная семантика и узловая механика. Пункты [ARCH-2.2.1](#arch-2.2.1), [ARCH-2.2.3](#arch-2.2.3) и [ARCH-2.5](#arch-2.5) перенесены сюда из [specs/concept/02_architecture.md](../concept/02_architecture.md#arch-2.2) по решению владельца; в concept на их месте — указатели.

### 2.2 Объекты узла

<a id="arch-2.2-impl"></a>

**Объекты узла:** БД состояния (живые записи + ретроспективный буфер), sync queue.

### 2.2.1 Транспорт = социальный граф

<a id="arch-2.2.1"></a>

1. **Транспорт = социальный граф.** Запись ретранслируется только узлам с активной LINK. Компонент связности — изолированная вселенная данных: записи человеческого компонента физически не достигают бот-кластеров (двойная изоляция). Свежий ключ без связей не получает трафика; установление LINK включает слив состояния.

### 2.2.2 Обработка записи

<a id="arch-2.2.2-impl"></a>

2. **Обработка записи:** проверка (подписи, каноническая форма, применимость, [ARCH-2.4.8](../concept/02_architecture.md#arch-2.4.8)) → применение к БД → постановка в sync queue → рассылка соседям.

### 2.2.3 Anti-entropy

<a id="arch-2.2.3"></a>

3. **Anti-entropy.** Утаивание записей соседом обнаруживается сверкой через других соседей; риск единственного моста — [LIM-10.9](../concept/10_limitations.md#lim-10.9). Механика сверки (реконсиляция по диапазонам времени и хешам) — [ARCH-2.2.3-impl](#arch-2.2.3-impl) (implementation).

<a id="arch-2.2.3-impl"></a>

3. **Anti-entropy.** Периодическая сверка множеств записей с каждым соседом (реконсиляция по диапазонам времени и хешам); расхождения подтягиваются.

### 2.5 Синхронизация и сходимость

<a id="arch-2.5"></a>

Согласованность — в пределе; в моменте — субъективные виды. Потребитель доверия всегда читает текущее состояние. Цензура соседа подавляет доставку, но не искажает семантику: задержанная запись применяется со своей $t_{sign}$. Механика доставки (gossip при появлении записи, anti-entropy по расписанию) — [ARCH-2.5-impl](#arch-2.5-impl) (implementation).

<a id="arch-2.5-impl"></a>

Gossip при появлении записи + anti-entropy по расписанию.
